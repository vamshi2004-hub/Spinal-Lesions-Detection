# Automatic Detection of Spinal Lesions from CT Scans

## 📌 Project Overview

This project focuses on the automatic detection of spinal lesions from CT scans using Deep Transfer Learning.

The project uses the Xception deep learning architecture for image classification and detection of spinal lesions.

## 🎯 Objective

The main objective is to develop a deep learning-based system that can analyze CT scan images and assist in identifying spinal lesions.

## 🧠 Model

- Deep Transfer Learning
- Xception Architecture
- Image Classification
- Python
- TensorFlow / Keras

## 📂 Project Files

- `Final_xceptional_model_file.ipynb` — Final Xception model notebook
- `new_train_model.ipynb` — Training notebook
- `train_model.ipynb` — Model training implementation
- `app.py` — Application file
- `Group doc(final).pdf` — Project documentation
- `README.dataset.txt` — Dataset information
- `README.roboflow.txt` — Roboflow dataset information

## 📊 Dataset

The project uses the Backspine dataset provided through Roboflow.

Dataset source and licensing information are available in `README.dataset.txt`.

- Python

- Roboflow

## 🚀 How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the training/model cells.
5. Use `app.py` to run the application.
